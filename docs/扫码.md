# 扫码客户端（平台版）

## 引入脚本

```html
<script src="https://iot.luatos.com/ai_app/luatos/js/scan-client.js"></script>
```

该脚本在全局挂载 `ScanClient` 对象，只提供两个方法，业务代码无需感知运行环境。

> 项目内业务页面（如设备管理页）无需直接引用本脚本，由页面逻辑通过
> `App.config.SCAN_CLIENT_JS`（`BASE_HOST` 域名拼接）动态注入。

## 运行环境与扫码方式

| 打开方式 | 扫码方式 |
| --------- | ------------------------------------ |
| 作为 iframe 嵌入宿主（生产宿主 `https://mobile.d3inf.com`） | 宿主原生扫码（postMessage 协议） |
| 浏览器直接打开（https） | 本机摄像头实时扫码（html5-qrcode，后置优先，级联兜底） |
| 浏览器直接打开（http 非 localhost / 本地 file://） | 摄像头不可用，自动降级为相册选图识别 |

摄像头启动失败（权限被拒 / 无摄像头 / 被占用等）时，浮层内展示失败原因，并保留两个出口：

- **重试摄像头**：重新尝试启动摄像头；
- **从相册选择**：选一张二维码图片直接识别（不依赖摄像头权限与安全上下文，任何打开方式均可用）。

## 提供的方法

### ScanClient.send(action)

请求 / 取消扫码。

- `ScanClient.send()` 或 `ScanClient.send('open')`：
  - iframe 内 → 请求宿主打开原生扫码器；
  - 独立打开 → 打开自带扫码浮层（摄像头取景 + 相册入口）；
- `ScanClient.send('cancel')`：
  - iframe 内 → 请求宿主取消正在进行的扫码；
  - 独立打开 → 关闭扫码浮层并释放摄像头。

### ScanClient.onResult(callback)

注册接收回调，扫码结果或状态变更时触发。**可多次注册。**

```javascript
ScanClient.onResult(function (type, payload) {
  // type:    'accepted' | 'ready' | 'result' | 'error'
  // payload: { state, resultText?, contentType?, code?, message? }
});
```

| type      | 含义                            | payload 关键字段                              |
| --------- | ------------------------------- | --------------------------------------------- |
| accepted  | 扫码请求已受理，正在启动摄像头    | `state: 'scanning'`                           |
| ready     | 扫码界面就绪，可扫码             | `state: 'scanning'`                           |
| result    | 扫码完成（摄像头 / 相册识别一致） | `state: 'success'`、`resultText`、`contentType` |
| error     | 扫码失败                        | `state: 'error'`、`code`、`message`           |

- `resultText`：扫码原始字符串，原样展示即可（用 `textContent`，不要 `innerHTML`）。
- `contentType`：客户端识别出的内容类型（`url` / `text` / `json` / `email` / `tel` / `wifi` / `vcard` / `geo` / `empty`）。
  不同内容类型由你的业务自行决定如何处理；客户端不会自动执行任何结果（不跳转、不拨号、不连接）。

### 独立打开时的 error code 说明

| code                   | 含义                                            |
| ---------------------- | ----------------------------------------------- |
| camera_error           | 摄像头启动失败（`message` 已含具体原因与建议）      |
| insecure_context       | 当前环境不允许调用摄像头（需 https 或 localhost）  |
| h5_qrcode_load_failed | html5-qrcode 扫码库加载失败（检查网络后重试）      |

iframe 内的 `not_iframe` 错误已不再出现：独立打开时自动走本机摄像头 / 相册兜底。
